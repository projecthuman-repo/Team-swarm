# conventions/

Optional project-specific rules, referenced from `AGENTS.md`. Add one file
per area (e.g. `python.md`, `api.md`, `frontend.md`) with the concrete
conventions agents must follow when editing that part of the target repo.

These files are the operator's main steering surface: when an agent
produces work you would reject, encode the correction here (teacher, not
doer) instead of hand-fixing the code.
